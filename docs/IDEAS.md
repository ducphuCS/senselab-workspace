# Letter of Intention

The project is an application built for operations of a Sensory lab. The roles of this lab are to support the product development via define sensory attributes, develop sensory methods, recruit panelists, run experiments, and analyze data.

1. Need to become a centralized workspace for daily work of Sensory Lab.
2. Support users to track the timeline and progress of experiments.
3. Track performance of panels and panelists
4. Analyze and support decision making based on sensory data.
5. Consist 4 main group of functions (1) Overview (2) Library (3) Lab (4) Analyze
6. **Overview** focus on the experiments, projects and workloads of individuals.
7. **Library** contain pre-prepared information before the test happens, such as test methods, panelists, panels, set of attributes, etc.
8. **Lab** is where the experiments and the tests actually happen, such as results, samples information.
9. **Analyze** show the analytical results, such as ANOVA tables, correlation matrix, panel performance, trends, etc.
